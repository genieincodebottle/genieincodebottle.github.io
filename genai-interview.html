🎨 Generative AI Fundamentals

What is Generative AI?
Generative AI refers to a class of artificial intelligence models that can generate new data or content based on the data they were trained on. These models can create text, images, audio, and more.

Evolution Timeline:
  • Early developments (1950s-2000s): Basic text generation, rule-based systems
  • Rise of neural networks (2010s): Deep learning advances, like RNNs and LSTMs
  • Transformer architecture (2017): Revolutionized natural language processing
  • GPT models (2018-present): Increasingly powerful language models
  • Diffusion models (2020-present): Advanced image generation capabilities
How does a Generative Adversarial Network (GAN) work?
A GAN consists of two neural networks: a generator and a discriminator. The generator creates fake data, while the discriminator tries to distinguish between real and fake data. Both networks are trained simultaneously in a game-like scenario where the generator improves its ability to create realistic data, and the discriminator gets better at detecting fakes.
What is the difference between generative and discriminative models?
  • Generative Models: Learn the underlying data distribution to generate new samples. Examples: GANs, VAEs, language models
  • Discriminative Models: Learn decision boundaries to classify existing data. Examples: SVM, logistic regression, BERT for classification

🔄 Transformer Architecture

What is the Transformer architecture and why is it significant?
The Transformer architecture is a deep learning model introduced by Vaswani et al. in 2017, designed to handle sequential data with a mechanism called self-attention. It is significant because it efficiently processes long-range dependencies in data, enabling high-quality text generation, translation, and other language-related tasks.

Key Innovation: Unlike RNNs that process sequences step-by-step, Transformers can process entire sequences in parallel, making them much faster and better at capturing long-range dependencies.
What is self-attention and how does it work?
Self-attention allows the model to weigh the importance of different words in a sequence when generating an output. For each word, the mechanism computes attention scores relative to all other words, helping the model understand contextual relationships.

Example: In the sentence "The cat sat on the mat because it was tired," self-attention helps the model understand that "it" refers to "the cat" by looking at the whole sentence simultaneously.
What are the main components of the Transformer architecture?
  • Encoder Stack: Processes input data
  • Self-Attention Mechanism: Captures relationships between words
  • Feed-Forward Networks: Further processes information
  • Layer Normalization: Improves training stability
  • Residual Connections: Helps with gradient flow
  • Decoder Stack: Generates output sequences
  • Positional Encoding: Provides word position information

🧠 Large Language Models

What is a Large Language Model (LLM)?
A Large Language Model (LLM) is a type of artificial intelligence model that uses deep learning techniques to understand, generate, and manipulate human language. Examples include GPT-3, GPT-4, Claude, Gemini, and LLaMA.
What is the difference between GPT and BERT?
  • GPT (Generative Pre-trained Transformer):
    • Decoder-only model
    • Unidirectional (left-to-right)
    • Designed for text generation
    • Autoregressive generation
  • BERT (Bidirectional Encoder Representations from Transformers):
    • Encoder-only model
    • Bidirectional processing
    • Designed for understanding tasks
    • Excellent for classification and Q&A
What is the "temperature" parameter in LLMs?
The temperature parameter controls the randomness of the model's output:
  • Lower temperature (closer to 0): More deterministic, focused outputs
  • Higher temperature (closer to 1): More diverse, creative outputs
  • Temperature = 0: Always selects the most likely next token

🎯 Embedding Models

What are word embeddings?
Word embeddings are dense vector representations of words that capture their semantic meaning and relationships, enabling models to process text in a numerical form. They represent words as points in a high-dimensional space where semantically similar words are closer together.
What is the difference between sparse and dense embeddings?
  • Sparse Embeddings:
    • Many zero values
    • High-dimensional
    • Traditional methods (TF-IDF)
    • Good for exact matching
  • Dense Embeddings:
    • Few or no zero values
    • Lower-dimensional
    • Neural network-based
    • Better for semantic similarity
What is semantic search and how does it relate to embeddings?
Semantic search aims to understand the intent and contextual meaning of queries, rather than just matching keywords. Embeddings enable semantic search by:
  • Representing queries and documents in the same vector space
  • Allowing similarity comparisons based on meaning
  • Capturing nuanced relationships between concepts
  • Handling synonyms and related terms effectively

📚 Retrieval-Augmented Generation (RAG)

What is Retrieval-Augmented Generation (RAG)?
RAG is a framework that combines retrieval-based methods with generative models to improve the accuracy and relevance of generated content by incorporating external information. It retrieves relevant documents or passages from a knowledge base and uses this information to guide the generation process.
What are the components of a RAG model?
  • Retriever: Fetches relevant information from knowledge base
  • Generator: Uses retrieved information to produce final output
  • Knowledge Base: Repository of documents/information
  • Embedding Model: Converts text to vector representations
  • Vector Database: Stores and searches embeddings efficiently
What are the benefits of using RAG?
  • Improved accuracy and factual correctness
  • Access to up-to-date information
  • Domain-specific knowledge integration
  • Reduced hallucination
  • Transparency through source attribution
  • Cost-effective alternative to fine-tuning

🎯 Fine-tuning & Training

What is fine-tuning in the context of LLMs?
Fine-tuning involves adapting a pre-trained LLM to a specific task or dataset by continuing its training on task-specific data, improving performance on that particular task. It's more efficient than training from scratch as it leverages existing knowledge.
What is RLHF (Reinforcement Learning from Human Feedback)?
RLHF is a technique that incorporates human feedback into the fine-tuning process:
  1. The model generates responses to prompts
  2. Human evaluators rate these responses
  3. A reward model is trained on these ratings
  4. The language model is fine-tuned using reinforcement learning with the reward model
This helps align the model's outputs with human preferences and values.
What are LoRA and QLoRA?
  • LoRA (Low-Rank Adaptation):
    • Decomposes weight updates into lower-rank matrices
    • Significantly reduces trainable parameters
    • More memory efficient
  • QLoRA (Quantized LoRA):
    • Combines LoRA with quantization techniques
    • Uses lower precision (4-bit) representations
    • Enables fine-tuning of larger models on consumer hardware

💬 Prompt Engineering

What is prompt engineering?
Prompt engineering involves designing and optimizing input prompts to guide language models to generate desired outputs. It includes providing clear instructions, examples, context, and constraints to improve model performance.
What are different types of prompting techniques?
  • Zero-shot: No examples provided, relies on pre-training
  • One-shot: Single example given
  • Few-shot: Multiple examples provided
  • Chain-of-Thought: Encourages step-by-step reasoning
  • Tree-of-Thoughts: Explores multiple reasoning paths
  • ReAct: Combines reasoning and acting
What makes an effective prompt?
  • Clarity: Clear and specific instructions
  • Context: Relevant background information
  • Examples: Demonstration of desired output format
  • Constraints: Specific requirements or limitations
  • Role Definition: Specify the AI's role or expertise
  • Output Format: Define expected response structure

🚀 Advanced Topics

What is GraphRAG?
GraphRAG (Graph Retrieval-Augmented Generation) enhances traditional RAG by using knowledge graphs to capture relationships between entities. It combines the structured representation of knowledge graphs with the retrieval capabilities of RAG systems to provide more contextually aware and relationship-rich responses.
What is Agentic AI?
Agentic AI refers to AI systems that can act autonomously to achieve goals. These systems can:
  • Understand natural language instructions
  • Make decisions and plan actions
  • Interact with external tools and APIs
  • Maintain context over long interactions
  • Learn from feedback and improve
What are the key components of an AI Agent system?
  • LLM Core: The foundational language model
  • Memory System: Short-term and long-term memory management
  • Planning Module: Task decomposition and strategy
  • Tool Integration: Access to external APIs and functions
  • Feedback Loop: Learning and improvement mechanism
  • Safety Guardrails: Constraints and safety measures

🆕 Latest Q&A from Companies

How do LLMs balance between fluency and factual accuracy?
LLMs often prioritize fluency due to their training on language patterns, which can lead to confident-sounding but inaccurate responses (hallucination). Strategies to improve accuracy include:
  • External grounding with verified sources
  • Reinforcement learning with accuracy-focused rewards
  • Few-shot learning with accurate examples
  • Uncertainty quantification
  • Constrained decoding to limit improbable outputs
How would you protect against prompt injection in production systems?
  • Input Validation: Filter suspicious commands before API calls
  • System Prompts: Reinforce role and limitations
  • Input Sanitization: Remove potential injection phrases
  • Output Filtering: Catch unexpected responses
  • Content Moderation: Use API safety features
  • Monitoring: Flag suspicious interactions
  • Rate Limiting: Prevent rapid-fire attempts
What is the difference between dense and sparse search?
  • Dense Search:
    • Uses continuous vector representations
    • Better for semantic understanding
    • Handles synonyms and related concepts
    • Example: [0.1, -0.3, 0.7, 0.2, -0.1, ...]
  • Sparse Search:
    • Uses high-dimensional vectors with many zeros
    • Excellent for exact matching and Boolean queries
    • More interpretable results
    • Example: [0, 0, 1, 0, 0, 0, 1, 0, 0, 1, 0, ...]
Why is it important to use the same embedding model for both storing and querying data?
Different embedding models create vector representations in distinct "embedding spaces" that are not directly comparable. Using mismatched embeddings would lead to:
  • Unreliable similarity scores
  • Poor retrieval performance
  • Meaningless comparisons between vectors
  • Inconsistent semantic relationships
Best Practice: Always use the same embedding model for encoding stored information and generating query embeddings.
