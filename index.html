3 weeks Math for ML & AI Phase 1 - Core:
Linear Algebra: Dot product, matrix ops
Calculus: Derivatives, gradients, chain rule
Probability & Statistics: Descriptive stats, conditional probability, independence, Bayes' rule, expectations, basic distributions
Optimization: Gradient descent, learning rate, regularization basics
Applied Math: Softmax, loss functions, backprop basics

Continue to Phases 2 and 3 if you are interested in ML and research oriented roles

Phase 2 - Intermediate:
Linear Algebra: Matrix norms, projections, decomposition
Calculus: Partial derivatives, multivariable calculus, Markov chains/processes
Probability & Statistics: Marginal probability, statistical tests, confidence intervals, hypothesis testing
Optimization: Adam, learning rate schedulers, L1/L2 regularization
Applied Math: Numerical stability, gradient clipping

Phase 3 - Advanced (Research Level):
Linear Algebra: Eigenspaces, SVD, tensor ops, PCA
Calculus: Jacobian, Hessian, Taylor approximations
Probability & Statistics: Entropy, KL divergence, information theory, statistical estimation, advanced distributions
Optimization: Convex and constrained optimization (Lagrangian, KKT)
Applied Math: Full backprop, loss design, second-order methods
